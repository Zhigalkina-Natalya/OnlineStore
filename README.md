# Проект интернет-магазина

Учебный проект интернет-магазина.  
Создан с использованием **Django** и **Bootstrap**.  
Проект предназначен для отработки базовых навыков работы с Django, шаблонами и GitFlow.

## Установка и запуск проекта

### 1. Клонирование репозитория
```
git clone https://github.com/Zhigalkina-Natalya/OnlineStore
```

### 2.Установка зависимостей:
Используйте инструмент Poetry. Запустите команду в терминале, находясь в корневом каталоге вашего проекта.
```
poetry install
```
### 3. Активация виртуального окружения
```
poetry shell
```
### 4. Применение миграций
```
python manage.py migrate
```
### 5. Запуск локального сервера
После запуска проект будет доступен по адресу: http://127.0.0.1:8000/
```
python manage.py runserver
```

## Используемые технологии
- Python 3.13
- Django 6.0
- Poetry
- Bootstrap 5
